# TeleSec
La plataforma de EuskadiTech para centros educativos, que funciona sin internet y es de codigo abierto.

## Servicios necesarios para utilizar TeleSec:
1. Un servidor de CouchDB para sincronizar datos.
2. Internet, pero solo para la sincronización y para la primera ejecución.
    - Recomendamos mantener el internet para la sincronización en tiempo real.

## La seguridad: parte integral de TeleSec.
TeleSec encripta todos los datos con RSA antes de salir del dispositivo, para prevenir filtraciones de datos por un servidor mal configurado.

## Y lo mejor de todo: es gratis y de codigo abierto
No queremos lucrarnos de un programa tan bueno, con el que ha ayudado a tanta gente en diferentes centros educativos.
